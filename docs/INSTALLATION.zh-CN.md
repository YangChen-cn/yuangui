# 安装与权限说明

[English](INSTALLATION.md)

## 安装 DMG

1. 从[最新发布页](https://github.com/YangChen-cn/yuangui/releases/latest)下载 DMG。
2. 打开后将 `YuanGUI.app` 拖入 `Applications`。
3. 当前本地/个人分享版使用临时签名。按住 Control 点击应用，选择“打开”，再确认。
4. 如果 Gatekeeper 仍然拦截，请在“系统设置 → 隐私与安全性”中为 YuanGUI 点击“仍要打开”。

YuanGUI 需要 macOS 15 或更高版本。日常使用请运行打包后的 App，而不是 SwiftPM 的裸可执行文件。

## 被拒绝权限后的恢复

| 权限 | 用途 | 恢复方法 |
| --- | --- | --- |
| 屏幕录制 | 仅在你主动选择区域时，用于截图 OCR/翻译。 | “隐私与安全性 → 屏幕录制”启用 YuanGUI，再重新打开应用。 |
| 辅助功能 | 读取选中文本，并仅在你确认后替换可编辑文本。 | “隐私与安全性 → 辅助功能”启用 YuanGUI，再重试快捷键。 |
| 位置 | 显示大致位置的天气，不保存轨迹。 | “隐私与安全性 → 定位服务”启用 YuanGUI。 |
| 自动化（Music） | 在你选择 Apple Music 播放后控制 Music App。 | “隐私与安全性 → 自动化”中启用 YuanGUI → Music。 |
| 自动化（Finder） | 将你明确选中的清理项目移入废纸篓。 | “隐私与安全性 → 自动化”中启用 YuanGUI → Finder。 |

若系统不再弹窗，请退出 YuanGUI，在系统设置中调整后重新打开；屏幕录制和辅助功能通常必须重新启动应用。

## 清理边界

清理屋不使用管理员权限，不扫描整个主目录、不修改系统目录、不重置服务、不重建 Spotlight，也不做系统优化。所有候选项都可以预览、加入白名单，并在执行前查看本地操作记录。
